Para este dataset de ~352 MB el script secuencial (8.4 s) fue más rápido que Hadoop Streaming (23.5 s). Hadoop en modo standalone se ejecuta en una sola máquina, así que no obtiene paralelismo real entre nodos, pero sí paga costos fijos: arrancar la JVM, planificar el job, lanzar procesos Python independientes para el mapper y el reducer, ordenar (shuffle) y escribir archivos intermedios. El script secuencial lee el archivo una sola vez y acumula en memoria sin ese sobrecosto. MapReduce conviene cuando los datos son demasiado grandes para una máquina o están distribuidos en HDFS entre varios nodos, donde procesar en paralelo compensa los costos fijos.
